# المساهمة | Contributing

[العربية](#العربية) · [English](#english)

## العربية

أهلاً! أي تحسين يفيد الديوانيات والبيوت في الكويت مرحّب فيه 🇰🇼

### طرق المساهمة
- **بلّغ عن مشكلة:** افتح [Issue](https://github.com/29kuwait/diwaniya-kuwait/issues/new/choose) واكتب نوع الرسيفر ونسخة الأندرويد.
- **اقترح ميزة:** افتح Issue واشرح الفكرة وكيف تفيد الديوانية.
- **عدّل الكود:** اعمل Fork، وجرّب تعديلك على جهاز حقيقي، وافتح Pull Request.

### قبل ما ترفع
- لا ترفع باسورد واي فاي حقيقي أو مفاتيح توقيع (`*.jks`).
- لا تغيّر عنوان IP الخاص بشبكتك في الملفات المرفوعة.
- اكتب في الـ Pull Request وش غيّرت وعلى أي جهاز جرّبته.

شكراً لمساهمتك!

## English

Welcome! Any improvement that helps Kuwaiti diwaniyas and homes is appreciated 🇰🇼

### Ways to contribute
- **Report a bug:** open an [issue](https://github.com/29kuwait/diwaniya-kuwait/issues/new/choose) with your box model and Android version.
- **Suggest a feature:** open an issue describing the idea and how it helps a diwaniya.
- **Change the code:** fork, test your change on a real device, and open a pull request.

### Before you submit
- Never commit a real Wi-Fi password or signing keys (`*.jks`).
- Do not commit your own network's IP address.
- In your pull request, say what you changed and which device you tested on.

Thank you for contributing!
